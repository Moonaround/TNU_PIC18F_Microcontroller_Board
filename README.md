# TNU PIC18F Microcontroller Board Replication

## Project Overview
This repository contains the engineering design files to replicate the **TNU PIC18F Microcontroller Board** for the Microcontrollers course footprint project. 

## Technical Specifications
* **Target Architecture:** PIC18F 40-Pin Microcontroller variant
* **Design Toolchain:** KiCad 8.0 (Ubuntu Linux environment)
* **Source Reference Assets:** 
  * Schematic Specifications: `Cadence_Pic40_TNU_PCB_schematic_v2.pdf`
  * Inventory Component Ledger: `Cadence_Pic40_TNU_Bill_Of_Material.xlsx`
